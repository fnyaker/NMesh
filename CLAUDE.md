# NMesh — instructions live in AGENTS.md

The engineering charter and the working rules for this project are kept in
**one** file, [`AGENTS.md`](AGENTS.md), read by every coding agent. This file
only points there, so the two can never disagree.

The specialised agents and their file ownership are declared in
[`opencode.json`](opencode.json). Prefer several agents in parallel when the
work does not overlap; background every subagent and every long command.
